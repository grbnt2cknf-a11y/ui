# Altura — studio di riferimento

Replica della landing "Altura / Casa Pietra" vista nella registrazione dello schermo: è il
modello visivo di tutto il portfolio.

Le immagini (`assets/`) sono state estratte e ripulite dalla registrazione con gli script
`../../tools/altura_*.py`. Appartengono all'autore del video originale: **usare solo come
riferimento interno**, non nel portfolio pubblico né nelle sponsorizzate.

- Logo: Poppins 500 allargato del 2% (fit sul video, IoU 0.97).
- Titoli del tour: Inter 200; etichette: Geist Mono; interfaccia: Inter.
- Il video si ferma alla cucina, quindi il tour finisce lì; la sezione di chiusura è aggiunta.
